# AIchat-graph 使用说明

Windows 10／11 x64 免安装版本。程序自带 Node 运行时，不需要安装 Node、npm、Git 或
其他系统组件；讨论资料保存在你自己的目录，升级或删除程序不会删除资料。

## 第一次打开

1. 把下载的 ZIP **完整解压**到可写且长期保留的位置（例如 `D:\Tools\AIchat-graph`）。
   不要只复制其中的部分文件，也不要放入 Program Files 等需要管理员权限的位置。
2. 双击 `AIchat-graph.exe`。
3. 第一次会打开文件夹选择器：选择已有讨论库（目录里有 `graph.sqlite`），
   或新建一个空文件夹作为新的讨论库。取消选择会正常结束，不会创建或修改资料。
4. 服务就绪后会用默认浏览器打开阅读页。之后再次双击会直接打开上次的讨论库。

每个讨论库只会运行一个后台服务；重复双击不会启动多个实例。

## 日常使用

- 阅读、搜索、修改都在浏览器里进行；关闭网页只结束这次浏览，不影响后台服务。
- 页面「程序」菜单可以重新选择讨论库或退出本库服务。
- 也可以在命令行运行 `AIchat-graph.exe --stop`，正常停止当前讨论库的服务。
- 使用其他讨论库：`AIchat-graph.exe --choose-workspace`。

## 给 Agent 使用

- 推荐入口是包根 `aichat.cmd`，它直接使用包内运行时与 CLI，不依赖 PATH：
  `aichat.cmd topics --workspace <讨论库>`、`aichat.cmd read ...`。
- 通用 Skill 在 `app\skills\aichat-graph`；需要时运行
  `app\tools\install-skill.ps1 -Host workbuddy`（或 `-Host codex`、`-Target <目录>`）
  主动安装到宿主。首次打开程序不会安装任何 Skill。
- Skill 与程序可以分别使用；安装或更新 Skill 不会改动讨论资料。

## 更新程序

1. 下载新版本的 ZIP，解压到旧程序目录**之外**。
2. 先退出旧程序正在服务的讨论库（页面「程序」菜单，或旧程序 `--stop`）。
3. 从新包双击 `更新已有程序.cmd`，选择旧程序目录并确认。
4. 完成后从原位置打开程序。原程序的 `.aichat` 本机设置与所有讨论库都会保留。

更新只替换程序文件，不复制、不删除讨论资料；也不会停止仍在运行的进程。

## 移除程序

先退出本包服务的讨论库，然后删除整个解压目录即可。外部讨论库、导出的 HTML
以及你自行安装的 Skill 不会自动删除，需要时请自行处理。

## 排错

- 启动失败的简要原因写入包根 `.aichat\logs\entry.log`。
- 讨论库、服务状态与日志在讨论库内 `.aichat\` 下。
- 提示程序包不完整时，请重新完整解压下载的 ZIP。
- 本版本不注册系统服务、不写注册表、不修改 PATH、不创建快捷方式。
